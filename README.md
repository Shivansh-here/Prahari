## 🚀 Overview

**Prahari** is a full-stack tourist safety platform engineered to cut emergency response times by removing manual dispatch steps. It provides real-time SOS alerts, live GPS tracking, and hyper-local environmental alerts for tourists navigating unfamiliar locations.

---

## 🛠️ Tech Stack

- **Mobile App:** React Native
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Blockchain:** Solidity, Hardhat (Ethereum Smart Contracts)
- **Real-time Comms:** Socket.IO

---

## ✦ Core Features

### 1. 🚨 Real-time SOS & Live Tracking
Using `Socket.IO`, the platform maintains a persistent WebSocket connection. When a tourist triggers an SOS, their live GPS coordinates are streamed instantaneously to the nearest police authority dashboard, bypassing traditional dispatch delays.

### 2. 🔐 Blockchain Digital Tourist ID
Identity verification is handled via a custom Solidity smart contract. Tourist identities are verified via DigiLocker and minted as tamper-proof Digital IDs with strict role-based access for tourists, law enforcement, and supervisors.

### 3. 🧠 AI-Driven Geo-Fencing
Proactive alerts are triggered when tourists cross into designated high-risk zones. Anomaly detection algorithms monitor movement patterns to flag suspicious deviations in travel routes.
